#### Cài đặt Kiro IDE

Để cài đặt Kiro IDE, các bạn truy cập vào trang chủ của [Kiro](https://kiro.dev/) hoặc tải Kiro tại đường link sau với hệ điều hành tương ứng: https://kiro.dev/downloads/

![Image](/images/1-setup/1.png?featherlight=false&width=90pc)


ℹ️ **Note**: Với máy Windows dùng CPU ARM, hiện chưa có bản cài đặt Kiro chính thức từ nhà sản xuất. Chúng ta sẽ phải chờ bản hỗ trợ sau.

- Chọn **“I accept the agreement”** sau đó nhấn **“Next”**

![Image](/images/1-setup/2.png?featherlight=false&width=90pc)

- Tại bước này, các bạn có thể chọn đường dẫn đến nơi các bạn muốn cài đặt Kiro IDE. Nếu không có thay đổi gì (default) nhấn **“Next”**

![Image](/images/1-setup/3.png?featherlight=false&width=90pc)


- Nhấn **“Next”**

![Image](/images/1-setup/4.png?featherlight=false&width=90pc)

- Bước tiếp theo là tùy chọn, tức là các bạn sẽ có thể làm hoặc không. Tuy nhiên để sử dụng Kiro IDE một cách hiệu quả, các bạn nên tích chọn vào các ô sau:
  - **Create a desktop icon:** Tạo shortcut ở màn hình chính
  - **Add “Open with Kiro” action to Windows Explorer file context menu:** Thêm lựa chọn **“Open with Kiro”** vào menu chuột phải
  - Add **“Open with Kiro”** action to Windows Explorer directory context menu: Thêm lựa chọn **“Open with Kiro”** vào menu chuột phải khi click chuột phải vào folder
- Nhấn **“Next”**

![Image](/images/1-setup/5.png?featherlight=false&width=90pc)

- Nhấn **“Install”** để bắt đầu quá trình cài đặt

Quá trình cài đặt sẽ diễn tra trong khoảng từ 2-5 phút tùy theo cấu hình máy của bạn.

- Sau khi cài đặt xong tích chọn **“Launch Kiro”** (nếu chưa được chọn) và sau đó nhấn **“Finish”** để hoàn tất cài đặt

![Image](/images/1-setup/6.png?featherlight=false&width=90pc)
