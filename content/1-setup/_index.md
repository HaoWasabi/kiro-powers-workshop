#### Installing Kiro IDE

To install Kiro IDE, visit the [Kiro](https://kiro.dev/) homepage or download Kiro for your operating system from the following link: https://kiro.dev/downloads/

![Image](/images/1-setup/1.png?featherlight=false&width=90pc)

{{% notice note %}}
Kiro does not currently provide an official installer for Windows devices with ARM CPUs. We will need to wait for a future supported release.
{{% /notice %}}

- Select **“I accept the agreement”**, then click **“Next”**.

![Image](/images/1-setup/2.png?featherlight=false&width=90pc)

- At this step, you can choose where to install Kiro IDE. If you do not want to change the default location, click **“Next”**.

![Image](/images/1-setup/3.png?featherlight=false&width=90pc)

- Click **“Next”**.

![Image](/images/1-setup/4.png?featherlight=false&width=90pc)

- The next step is optional. However, to use Kiro IDE effectively, we recommend selecting the following options:
   - **Create a desktop icon:** Create a shortcut on the desktop.
   - **Add “Open with Kiro” action to Windows Explorer file context menu:** Add an **“Open with Kiro”** option to the file context menu.
   - Add **“Open with Kiro”** action to Windows Explorer directory context menu: Add an **“Open with Kiro”** option to the context menu when right-clicking a folder.
- Click **“Next”**.

![Image](/images/1-setup/5.png?featherlight=false&width=90pc)

- Click **“Install”** to begin the installation process.

The installation process will take approximately 2-5 minutes, depending on your computer's configuration.

- After the installation is complete, select **“Launch Kiro”** if it is not already selected, then click **“Finish”** to complete the installation.

![Image](/images/1-setup/6.png?featherlight=false&width=90pc)
